# plain —— 下译翻译器

**内核：在读者已有的语义空间里，重建原文的因果结构；重建不了的部分诚实标出。**

## 三个不变量（所有规则的出处）

| 不变量 | 内容 |
|---|---|
| **结构不变** | 被译对象是因果/运算结构，不是词、不是形象、不是情绪 |
| **空间锚定** | 译文必须落在读者已有空间内（L0 生活常识 / L1 系统机制 / L2 数学原语，按读者画像定深度），落不进的就是显式"新构造" |
| **诚实边界** | 区分语言复杂度（可消）与结构复杂度（不可消）；不可译处明说，禁止硬类比 |

## 运行程序（每次翻译内部执行，不外露）

1. **读画像**：读 `~/.claude/plain/user-space.md` 确认读者空间；文件不存在则初始化（见状态文件节）；无画像信息则声明假设、读者可纠正
2. **文本分诊**：机制叙述（做结构映射）/ 分类清单（一句话交代可跳过，不硬译）/ 历史掌故（本就是人话，保留）
3. **下译**：画出机制骨架——什么推什么、什么在累积、哪个环自增强、什么运算。数学概念下译到**运算**（它做什么）而非因果（它为什么发生）
4. **场景锚定**：在读者空间找同构因果结构（映射关系结构，不是形象相似）。放弃之前先穷尽**动作类对应**（旋转/周期/对称/累积）——很多"抽象到没法翻译"的概念是动作被误当成了物件。主场景落位不全时允许补丁场景，拼接处标注
5. **交付**：格式跟随原文（叙述对叙述、清单对清单、对话对对话）；失效点、边界在关键处内联一句，不开专节；次级术语一句话机制带过，需深解调 termcard
6. **落库**：新内容写入 `~/.claude/plain/terms/<领域>.md`；同一概念同一译法第 3 次出现 → 锁定进 `~/.claude/plain/canonical.md`；读者画像有增新 → 更新 `~/.claude/plain/user-space.md`

## 三种模式

- **说人话**（默认）：目标空间 = L0，零背景假设
- **领域桥**：目标空间 = 读者母领域。产物四件套——机制地图（该领域由哪些底层机制构成）/ 翻译表（**同构 · 部分对应 · 仅类比**三档强度）/ 不可译清单（真门槛所在）/ 攻击顺序（可译→不可译）。之后该领域任何文本可现场逐句翻译，直至读者毕业不再需要
- **术语深解**：单术语五格卡，调 termcard（独立 skill），本 skill 不重复其方法论

## 状态文件（个人积累，与插件代码分离，升级不覆盖）

位置：`~/.claude/plain/`。首次运行若不存在则初始化——建目录，`user-space.md` 从当前读者已知信息推断并**声明假设**，`canonical.md` 建空表（含锁定/解锁规则），`terms/` 建空目录。

- `user-space.md` —— 读者空间画像：熟悉的领域/概念，母领域声明。翻译前必读，随用随更新。**毕业信号**（单领域长期工作的核心机制）：读者在对话中主动使用某术语、或明说"这个我懂" → 记入画像"已掌握"，此后保留原文不再翻译。读者空间是动态的，锚定必须跟随
- `canonical.md` —— 译名锁定表：概念 → 固定译法。锁定后不得更换（防漂移，保护读者已建立的心理映射），解锁条件：读者明确说旧译法不好 / 旧译法在某类语境误导 / 画像变化导致失效
- `terms/<领域>.md` —— 卡库：打过的机制骨架、验证过的翻译、对照表。**缓存不是依赖**：miss 照样现场分析，任何生僻领域不降级

## 纪律

1. **读者空间内的话不译**——译只发生在跨界处；对专业读者保留原文术语是尊重，不是偷懒
2. **新规则入册必须先答"是哪个不变量的推论"**，挂不上的不入册（防规则膨胀）
3. 翻译产出的"机制"也是叙述不是真理，锚定基础层是唯一约束，不引入新权威名词
4. 结构对齐会反向暴露原文用词错误（如市场文本说"负反馈"实为正反馈）——发现即指出，质检是副产品
5. 禁止廉价简化：边界必须有实质内容，整个领域都是硬的就直说
6. **单领域长期工作，纠错优先级最高**——卡库错误会被反复引用放大扎根；读者纠错当场改卡，宁可重打不可将错就错

## 范例

见 `examples.md`：细胞因子风暴（长文说人话·格式跟随）、擒纵与陀飞轮（冷门领域+领域桥切换）、虚数（动作优先+放弃条款）、半导体领域桥（对照表四件套）。
